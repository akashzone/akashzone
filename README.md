## Featured Project

### LocalConnect – MERN Marketplace
**Connecting local business owners with student developers**

A full-stack marketplace demonstrating end-to-end application development, from authentication and authorization to project lifecycle management and reviews.

**What I Built:**
- **Authentication** – JWT with HTTP-only cookies, Google OAuth, refresh token flow
- **Authorization** – Role-based middleware for Students, Business Owners, and Admins
- **REST APIs** – Complete CRUD operations for projects, applications, profiles, and reviews
- **Database Design** – MongoDB schema modeling for users, projects, applications, and reviews
- **File Management** – Multer + Cloudinary integration for profile images and resume uploads
- **UI/UX** – Responsive React frontend with protected routes and role-based dashboards
- **Image Processing** – Profile image cropping and editing features

**Tech Stack:**
Node.js • Express.js • MongoDB • React • Tailwind CSS • JWT • Google OAuth • Cloudinary

**Status:** Core features complete; chat and admin panel in progress.

**Repository:** [LocalConnect on GitHub](https://github.com/akashzone/localconnect)
