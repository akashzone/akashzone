# 🚀 Featured Projects

## 🎓 SkillForge LMS

A full-stack Learning Management System built using the MERN Stack.

### Highlights

- 👨‍🏫 Separate Student and Instructor dashboards
- 🔐 JWT Authentication with Role-Based Access Control
- 🔑 Password hashing using bcrypt
- 📚 Course, Section, and Lesson management
- 🎥 Lecture video uploads using Multer & Cloudinary
- 📈 Student enrollment and course progress tracking
- 🔄 26 REST APIs across Authentication, Courses, Sections, Lessons, Uploads, Enrollment, and Progress modules
- ⚡ React Context API with Axios for frontend state management
- ☁️ Frontend deployed on Vercel and backend deployed on Render

**Tech Stack**

React • Node.js • Express.js • MongoDB • Mongoose • JWT • bcrypt • Cloudinary • Multer • Axios • Tailwind CSS

🔗 **Repository:**  
https://github.com/akashzone/skillforge-lms

🌐 **Live Demo:**  
https://skillforge-lms-kohl.vercel.app/

## 🤖 Conversa AI

A full-stack AI chat application powered by Google's Gemini API.

### Highlights

- 🤖 AI conversations powered by Gemini API
- 🔐 Secure user authentication with JWT
- 💬 Persistent chat history stored in MongoDB
- 📂 Continue and delete previous conversations
- 🔒 Backend proxy to protect API keys
- ⚡ REST APIs built with Express.js
- ☁️ Frontend deployed on Vercel and backend deployed on Render

**Tech Stack**

React • Node.js • Express.js • MongoDB • Gemini API • JWT • Axios • Tailwind CSS
